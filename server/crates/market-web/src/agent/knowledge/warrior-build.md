# 战士一转：命中、单攻与省药的取舍

## 默认选择

走力量主属性、敏捷满足装备的通用路线。强力攻击先承担稳定单杀，群体攻击先开一阶备用，精准打击按漏怪情况提前。生命恢复的第一点能改善补血效率；不要为单个大伤害数字忽略打空和药费。

## 为什么这样点

一转抢图或分工后，常常一次只能打到一两只怪，先提高单攻的可靠性更容易兑现收益。有稳定密集平台或队友聚怪时，可以把群体攻击的投入提前。最大生命提升已是百分比加成，不是旧版“晚点就永久少血”，无需为这个旧理由开局直冲满。

## 另一种常见分配

经典世界攻略站更重视药耗：强力攻击 20、群体攻击 20、精准打击 15、生命恢复 6，共 61 技能点，放弃本篇默认的生命值和防御小投入。适合已能安全刷目标、希望多回血省钱的人。两个终点都有依据，区别是续航、额外血量和防御；不是所有战士都必须留钢铁之躯 1。

先把攻击暂留低耗蓝档、攒点后一起投入的做法也见于社区，但需要已经知道装备与目标怪。初学者按下方连续路线更好执行。若命中足够，可再研究减少精准打击的个性化分配。

## 练级衔接

10—20 先选地面蘑菇、树妖和章鱼；20—35 比较刺蘑菇、野猪与蚂蚁洞。近战不要因飞行怪纸面经验高就追着蝙蝠跑。二转先定剑、斧、钝器、枪或矛中的主武器，再投入对应精准技能。

## 通用输出与命中：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 强力攻击 → 1（累计投入1点）
2. 群体攻击 → 1（累计投入2点）
3. 生命恢复 → 1（累计投入3点）
4. 精准打击 → 5（累计投入8点）
5. 强力攻击 → 20（累计投入27点）
6. 群体攻击 → 19（累计投入45点）
7. 精准打击 → 15（累计投入55点）
8. 生命恢复 → 3（累计投入57点）
9. 最大生命提升 → 3（累计投入60点）
10. 钢铁之躯 → 1（累计投入61点）

30 级目标：强力攻击 20；群体攻击 19；生命恢复 3；精准打击 15；最大生命提升 3；钢铁之躯 1。共投入61点。

## 依据与适用范围

多篇攻略交叉整理；方案为编辑建议，未统计全服使用率。
