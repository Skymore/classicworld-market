# 猎人 Hunter：Mastery、爆炸箭与后期取舍

## 默认：基础先成形，再补群攻

先 Arrow Bomb 1，Bow Mastery 到 5，Bow Booster 到 5，才能点 Soul Arrow: Bow 1；随后补满 Mastery。这个起步兼顾开群攻、攻速和省箭。攻略与近期讨论对“Mastery 优先”的方向比较一致，但省箭、Final Attack、群攻的具体插入时点并不统一。

## 为什么 Mastery 优先

低伤害波动会让原本一两击的怪多吃一箭；稳定底线对实际清怪更有帮助。Booster 第一阶已有攻速提升，点到 5 的直接目的之一是开 Soul Arrow。不是“Booster 解锁 Final Attack”：Final Attack 只要求 Mastery 3。

## 常见备选

不缺箭、重视尽快满 Mastery 的玩家，可以只开 Booster 1，先补 Mastery，之后再补 Booster 5 和 Soul Arrow 1。小平台常有两三只怪或常被贴身时，也有人提前拿 Final Attack 1，再回去补基础。它触发后要主动释放，不能描述成每次自动追加。

满 Mastery 后，稳定群刷通常先补 Arrow Bomb；单体多、主动追加攻击使用频繁时，Final Attack 可更早投入。多点 Soul Arrow/Booster 是省蓝和延长持续，不是继续提高攻速。下方的后期续航终点是一种省事选择；也可减少持续类技能、转向 Amazon's Judgement 控制，但要重新核算 121 SP。

## 练级衔接

30—40 保留 Arrow Blow 单杀，把蘑菇、野猪、Stirge 对照起来；群攻成形后选择能真正打到多只的蚂蚁洞平台。弓有贴身挥击问题，不能只拿纸面倍率判断。Amazon's Judgement 是二转减速技能，与一转 The Eye of Amazon 不同。

## 省箭、Mastery 与群攻：可执行顺序

数字表示该技能加到的总等级，不是再加多少点。按从零开始的顺序执行，已有加点请按剩余 SP 调整。

1. Arrow Bomb → 1（累计 1 SP）
2. Bow Mastery → 5（累计 6 SP）
3. Bow Booster → 5（累计 11 SP）
4. Soul Arrow: Bow → 1（累计 12 SP）
5. Bow Mastery → 20（累计 27 SP）
6. Final Attack: Bow → 1（累计 28 SP）
7. Arrow Bomb → 30（累计 57 SP）
8. Final Attack: Bow → 30（累计 86 SP）
9. Amazon's Judgement → 1（累计 87 SP）
10. Bow Booster → 20（累计 102 SP）
11. Soul Arrow: Bow → 20（累计 121 SP）

70 级目标：Arrow Bomb 30；Bow Mastery 20；Bow Booster 20；Soul Arrow: Bow 20；Final Attack: Bow 30；Amazon's Judgement 1。合计已用 121 / 121 SP。

## 依据与适用范围

多篇攻略交叉整理；方案为编辑建议，未统计全服使用率。
