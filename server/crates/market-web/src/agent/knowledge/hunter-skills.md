# 猎人二转：技能前置与加点避坑

先按国际服英文技能名核对，避免把旧中文译名对应错：Bow Booster 要 Bow Mastery 5；Soul Arrow: Bow 要 Bow Booster 5；Final Attack: Bow 只要 Bow Mastery 3；Amazon’s Judgement 要 Bow Mastery 5，且不是一转的 The Eye of Amazon。

从这些二转技能全为零开始，一个仅用于先解锁功能的建议是 Arrow Bomb 1 → Bow Mastery 5 → Bow Booster 5 → Soul Arrow: Bow 1，共需 12 SP；有多少点就按顺序逐步完成。这是本站建议，不是官方最优配点。后续如何优先熟练度、攻击技能或增益时长，要看等级和现有投入。

Final Attack 在这份正式版提取中是触发后可使用的攻击，不能照搬旧版自动追加攻击解释。可让助手查询具体等级效果；安排完整配点前，应核对技能上限、前置和 SP 总预算。社区攻略仍会修改，想了解最新流派时可让助手联网查新。
