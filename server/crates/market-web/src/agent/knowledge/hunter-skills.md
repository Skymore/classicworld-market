# 猎人：精准弓、炸弹箭与后期取舍

## 默认：基础先成形，再补群攻

先炸弹箭 1，精准弓到 5，快速弓到 5，才能点无形箭：弓 1；随后补满精准弓。这个起步兼顾开群攻、攻速和省箭。攻略与近期讨论对“精准弓优先”的方向比较一致，但省箭、终极攻击、群攻的具体插入时点并不统一。

## 为什么精准弓优先

低伤害波动会让原本一两击的怪多吃一箭；稳定底线对实际清怪更有帮助。快速弓第一阶已有攻速提升，点到 5 的直接目的之一是开无形箭。不是“快速弓解锁终极攻击”：终极攻击只要求精准弓 3。

## 常见备选

不缺箭、重视尽快满精准弓的玩家，可以只开快速弓 1，先补精准弓，之后再补快速弓 5 和无形箭 1。小平台常有两三只怪或常被贴身时，也有人提前拿终极攻击 1，再回去补基础。它触发后要主动释放，不能描述成每次自动追加。

满精准弓后，稳定群刷通常先补炸弹箭；单体多、主动追加攻击使用频繁时，终极攻击可更早投入。多点无形箭/快速弓是省蓝和延长持续，不是继续提高攻速。下方的后期续航终点是一种省事选择；也可减少持续类技能、转向亚马逊的审判控制，但要重新核算 121 技能点。

## 练级衔接

30—40 保留断魂箭单杀，把蘑菇、野猪、蝙蝠对照起来；群攻成形后选择能真正打到多只的蚂蚁洞平台。弓有贴身挥击问题，不能只拿纸面倍率判断。亚马逊的审判是二转减速技能，与一转远程箭不同。

## 省箭、精准弓与群攻：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 炸弹箭 → 1（累计投入1点）
2. 精准弓 → 5（累计投入6点）
3. 快速弓 → 5（累计投入11点）
4. 无形箭：弓 → 1（累计投入12点）
5. 精准弓 → 20（累计投入27点）
6. 终极攻击：弓 → 1（累计投入28点）
7. 炸弹箭 → 30（累计投入57点）
8. 终极攻击：弓 → 30（累计投入86点）
9. 亚马逊的审判 → 1（累计投入87点）
10. 快速弓 → 20（累计投入102点）
11. 无形箭：弓 → 20（累计投入121点）

70 级目标：炸弹箭 30；精准弓 20；快速弓 20；无形箭：弓 20；终极攻击：弓 30；亚马逊的审判 1。共投入121点。

## 依据与适用范围

多篇攻略交叉整理；方案为编辑建议，未统计全服使用率。
