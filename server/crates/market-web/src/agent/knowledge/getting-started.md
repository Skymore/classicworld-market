# 经典世界国际服：版本与新手入口

本站面向 Nexon 的 Global MapleStory Classic World，不能套用现代 GMS、国台服经典版、Artale、MapleLand 或私服规则。

2026-10-20 官方发布说明列出：通过 Nexon Launcher 或 Steam 进入，支持 Windows 和 macOS；角色从 Maple Island 的 Beginner 开始。Grand Launch 日期为 2026-10-21。官方该次说明中的角色等级上限为 100。

这是发布时的规则快照，不代表后续更新永远不变。问最新开放区域、等级上限或版本时应联网核对。测试服曾有某内容，不等于正式服现在开放。
