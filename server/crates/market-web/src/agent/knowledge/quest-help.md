# 任务查询：前置、材料、交付和奖励

查任务时先解析准确名称与任务 ID，再读完整详情，保留等级、职业、前置任务、击杀数、收集数和奖励选择。任务物品不一定是普通掉落，任务需要某材料也不代表玩家背包已经有它。

例如这份客户端记录中，Teo’s Weird Hobby 最低等级为 8，要求击败 10 只 Slime 并收集 1 个 Slime Bubble；奖励为 124 EXP、277 Mesos 和 15 个 Fried Chicken，并连接后续任务。具体信息仍以任务工具与游戏内开放情况为准。

遇到同名分支、任务接不到或交不了，应对照前置、职业、完成阶段与 NPC，而不是凭老版本记忆补步骤。客户端存在任务不保证服务器已开放。
