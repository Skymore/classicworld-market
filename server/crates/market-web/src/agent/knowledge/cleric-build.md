# 牧师：圣箭单练、机动与固定队辅助

## 默认：治愈术起手，圣箭单练

先治愈术 1 减少补血开销，再开瞬间移动与魔力吸收，发展圣箭术。喵喵资料站和经典世界攻略站都有圣箭优先路线；这是一条有较多攻略支持的起点，不代表玩家没有其他选择。低级圣箭尚不如满级一转攻击时，继续用原主攻过渡。

## 固定队为什么不同

队友持续在同一范围刷怪时，把治愈术和神圣防护分别补到 5 级，才能学祝福。按当前技能说明，祝福能为队伍减伤，并提高治愈术的回复效果；旧版攻略说它增加命中，不适用于这里。下面的固定队方案把祝福加到 16 级、神圣防护留在 5 级；单练方案则把祝福留在 1 级、神圣防护加到 20 级，更重视自身生存。

## 瞬间移动与治愈术的争议

近期玩家也报告先高瞬间移动、继续用一转单体攻击，之后再补治愈术的路线：适合跨平台移动占时很多、主攻已经能稳定收怪的人；代价是新主攻或减伤较晚成形。治愈术仍能伤害不死怪，并非完全不能练级，但需要命中多个目标、地形适合、耗蓝能承担。不能把老版“群疗最省钱最快”当现成结论，也不能把一篇攻略的否定写成游戏规则。

## 练级衔接

先在刺蘑菇和僵尸蘑菇区形成稳定击杀，再比较地铁小幽灵与猴子森林的僵尸猴；更高等级再看幽灵和挖掘场不死怪。进入资格不等于适合刷，怪物生命值与命中要求要结合自身装备。

两套完整表是互斥示例。为省药而保留低级魔法盾的一转方案，仍要在危险图重新评估生存；治愈术、祝福不会保证你不死。

## 单练圣箭与减伤：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 治愈术 → 1（累计投入1点）
2. 瞬间移动 → 1（累计投入2点）
3. 魔力吸收 → 1（累计投入3点）
4. 圣箭术 → 30（累计投入33点）
5. 治愈术 → 5（累计投入37点）
6. 神圣防护 → 5（累计投入42点）
7. 祝福 → 1（累计投入43点）
8. 神圣防护 → 20（累计投入58点）
9. 魔力吸收 → 20（累计投入77点）
10. 瞬间移动 → 20（累计投入96点）
11. 治愈术 → 30（累计投入121点）

70 级目标：治愈术 30；瞬间移动 20；魔力吸收 20；圣箭术 30；神圣防护 20；祝福 1。共投入121点。

## 固定队辅助路线：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 治愈术 → 1（累计投入1点）
2. 瞬间移动 → 1（累计投入2点）
3. 魔力吸收 → 1（累计投入3点）
4. 圣箭术 → 30（累计投入33点）
5. 治愈术 → 5（累计投入37点）
6. 神圣防护 → 5（累计投入42点）
7. 祝福 → 16（累计投入58点）
8. 治愈术 → 30（累计投入83点）
9. 魔力吸收 → 20（累计投入102点）
10. 瞬间移动 → 20（累计投入121点）

70 级目标：治愈术 30；瞬间移动 20；魔力吸收 20；圣箭术 30；神圣防护 5；祝福 16。共投入121点。
