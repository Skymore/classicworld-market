# 牧师：圣箭单练、机动与固定队辅助

## 默认：Heal 起手，圣箭单练

先 Heal 1 减少补血开销，再开 Teleport 与 MP Eater，发展 Holy Arrow。NiaMeowDB 和 Classic World Guide 都有圣箭优先路线；这是一条有较多攻略支持的起点，不代表玩家没有其他选择。低级圣箭尚不如满级一转攻击时，继续用原主攻过渡。

## 固定队为什么不同

队友持续在同一范围刷怪时，把 Heal 补到 5，Invincible 补到 5，才开 Bless。Bless 在当前数据里是队伍减伤与 Heal 回复增益，不是旧版加命中的说明。下方固定队例子用 Bless 16 / Invincible 5；单练例子用 Bless 1 / Invincible 20，把更多点留给自身承伤。

## Teleport 与 Heal 的争议

近期玩家也报告先高 Teleport、继续用一转单体攻击，之后再补 Heal 的路线：适合跨平台移动占时很多、主攻已经能稳定收怪的人；代价是新主攻或减伤较晚成形。Heal 仍能伤害不死怪，并非完全不能练级，但需要命中多个目标、地形适合、耗蓝能承担。不能把老版“群疗最省钱最快”当现成结论，也不能把一篇攻略的否定写成游戏规则。

## 练级衔接

先在 Horny/Zombie Mushroom 区形成稳定击杀，再比较地铁 Jr. Wraith 与 Monkey Forest 的 Zombie Lupin；更高等级再看 Wraith 和挖掘场不死怪。进入资格不等于适合刷，怪物 HP 与命中要求要结合自身装备。

两套完整表是互斥示例。为省药而保留低级 Magic Guard 的一转方案，仍要在危险图重新评估生存；Heal、Bless 不会保证你不死。

## 单练圣箭与减伤：可执行顺序

数字表示该技能加到的总等级，不是再加多少点。按从零开始的顺序执行，已有加点请按剩余 SP 调整。

1. Heal → 1（累计 1 SP）
2. Teleport → 1（累计 2 SP）
3. MP Eater → 1（累计 3 SP）
4. Holy Arrow → 30（累计 33 SP）
5. Heal → 5（累计 37 SP）
6. Invincible → 5（累计 42 SP）
7. Bless → 1（累计 43 SP）
8. Invincible → 20（累计 58 SP）
9. MP Eater → 20（累计 77 SP）
10. Teleport → 20（累计 96 SP）
11. Heal → 30（累计 121 SP）

70 级目标：Heal 30；Teleport 20；MP Eater 20；Holy Arrow 30；Invincible 20；Bless 1。合计已用 121 / 121 SP。

## 固定队辅助路线：可执行顺序

数字表示该技能加到的总等级，不是再加多少点。按从零开始的顺序执行，已有加点请按剩余 SP 调整。

1. Heal → 1（累计 1 SP）
2. Teleport → 1（累计 2 SP）

4. Holy Arrow → 30（累计 33 SP）
