# 侠客：纯刀与先玩飞镖后转刀的取舍

## 默认：纯刀免洗点

一转已有二连击 20 时，二转轻功 1，精准短刀 5 后开快速短刀 1，再满精准短刀。继续用二连击过渡，逐步培养回旋斩。它在技能 11、21 阶段增加攻击次数，21 才是六连击；不能写成刚学一级就是六段。

## 为什么先精准短刀

这一路同时改善过渡主攻和之后的刀技；两份职业攻略对此方向一致。比起低精准短刀下急着堆回旋斩，先稳定伤害更容易减少剩血补刀。是否马上换主攻仍看你实际的击杀次数。

## 先用飞镖练级，之后再转短刀

先用爪与双飞斩，二转先拿轻功等通用收益，之后准备好短刀、装备属性与洗点再切换。作者们给出的转刀节点不完全一致，有约 40 级，也有约 45 级；不能承诺任何人到某一级免费无损转刀。原本已经点飞镖的玩家，也不能直接套下面“二连击已满”的前提。

## 妙手术还是移动/回复先

下方选择回旋斩后先轻功 5，再妙手术 30，借成功偷取后的攻击增益练级。另一方案更早满轻功和部分灵巧恢复，再回补妙手术，适合移动耗时或补给压力大的人。妙手术必须轻功 5；实际玩家指南讨论就纠正过跳过这个前置的错误。

## 武器和练级

力量刀飞按力量短刀的装备要求规划，普通刀则按对应要求；二者仍以幸运为主，不能看见“力量刀”就一路全力量。地面怪比追飞行怪更适合近战。快速短刀暂留 1 会较频繁补状态；不喜欢这一点，可将灵巧恢复的部分点移给快速短刀，保持总点数不超预算。

## 免洗点短刀、妙手术增益路线：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 轻功 → 1（累计投入1点）
2. 精准短刀 → 5（累计投入6点）
3. 快速短刀 → 1（累计投入7点）
4. 精准短刀 → 20（累计投入22点）
5. 回旋斩 → 21（累计投入43点）
6. 回旋斩 → 30（累计投入52点）
7. 轻功 → 5（累计投入56点）
8. 妙手术 → 30（累计投入86点）
9. 轻功 → 20（累计投入101点）
10. 灵巧恢复 → 20（累计投入121点）

70 级目标：轻功 20；精准短刀 20；快速短刀 1；回旋斩 30；妙手术 30；灵巧恢复 20。共投入121点。

## 依据与适用范围

多篇攻略交叉整理；方案为编辑建议，未统计全服使用率。
