# 侠客 Bandit：纯刀、Sindit 与 Steal 的取舍

## 默认：纯刀免洗点

一转已有 Double Stab 20 时，二转 Haste 1，Dagger Mastery 5 后开 Booster 1，再满 Mastery。继续用 Double Stab 过渡，逐步培养 Savage Blow。它在技能 11、21 阶段增加攻击次数，21 才是六连击；不能写成刚学一级就是六段。

## 为什么先 Mastery

这一路同时改善过渡主攻和之后的刀技；NiaMeowDB 与 Classic World Guide 对此方向一致。比起低 Mastery 下急着堆 Savage Blow，先稳定伤害更容易减少剩血补刀。是否马上换主攻仍看你实际的击杀次数。

## Sindit 是另一条路线

先用爪与 Lucky Seven，二转先拿 Haste 等通用收益，之后准备好短刀、装备属性与洗点再切换。作者们给出的转刀节点不完全一致，有约 40 级，也有约 45 级；不能承诺任何人到某一级免费无损转刀。原本已经点飞镖的玩家，也不能直接套下面“Double Stab 已满”的前提。

## Steal 还是移动/回复先

下方选择 Savage Blow 后先 Haste 5，再 Steal 30，借成功偷取后的攻击增益练级。另一方案更早满 Haste 和部分 Nimble Recovery，再回补 Steal，适合移动耗时或补给压力大的人。Steal 必须 Haste 5；实际玩家指南讨论就纠正过跳过这个前置的错误。

## 武器和练级

STR 刀飞按力量短刀的装备要求规划，普通刀则按对应要求；二者仍以 LUK 为主，不能看见“力量刀”就一路全 STR。地面怪比追飞行怪更适合近战。Dagger Booster 暂留 1 会较频繁补状态；不喜欢这一点，可将 Nimble Recovery 的部分点移给 Booster，保持总点数不超预算。

## 免洗点短刀、Steal 增益路线：可执行顺序

数字表示该技能加到的总等级，不是再加多少点。按从零开始的顺序执行，已有加点请按剩余 SP 调整。

1. Haste → 1（累计 1 SP）
2. Dagger Mastery → 5（累计 6 SP）
3. Dagger Booster → 1（累计 7 SP）
4. Dagger Mastery → 20（累计 22 SP）
5. Savage Blow → 21（累计 43 SP）
6. Savage Blow → 30（累计 52 SP）
7. Haste → 5（累计 56 SP）
8. Steal → 30（累计 86 SP）
9. Haste → 20（累计 101 SP）
10. Nimble Recovery → 20（累计 121 SP）

70 级目标：Haste 20；Dagger Mastery 20；Dagger Booster 1；Savage Blow 30；Steal 30；Nimble Recovery 20。合计已用 121 / 121 SP。

## 依据与适用范围

多篇攻略交叉整理；方案为编辑建议，未统计全服使用率。
