# 刺客：精准暗器、暴击与轻功谁先

## 默认路线

轻功 1 起手，精准暗器 5 后开快速暗器 1，再满精准暗器。之后默认发展强力投掷、轻功，后段补回复与快速暗器。下方顺序适合需要可靠收怪、再扩大暴击收益的普通练级。

## 为什么不是照抄老版暴击先满

当前的精准暗器能提高攻击力和飞镖回收收益。双飞斩有自身伤害规则，不要声称它和所有普通物理技能受精准暗器的方式完全相同。推荐精准暗器提前，理由是当前技能的实际收益与击杀稳定性，而不是旧版模板。

## 轻功提前的另一条路线

一份攻略建议先补精准暗器和暴击；另一份攻略则把轻功提到更前面。后一种做法也会先把精准暗器加到 5 级、快速暗器加到 1 级，保证基础攻速。经常跑图、跳平台，或队伍缺少移动速度时，可以先学轻功；守固定平台、伤害刚好差一次攻击时，先补暴击更直接。两条路线各有用途，没有适用于所有人的唯一顺序。

## 续航与操作

快速暗器的后续点数主要改善维持状态；致命恢复有触发与 30 秒间隔，不能算作每次暴击都回复。生命吸收要致命恢复 3，初期也不是稳定的免费回血替代品。保留补给，比较实际药耗。

## 练级衔接

继续用双飞斩。30—40级先沿用原来刷蘑菇、蝙蝠的地图，命中够再试风独眼兽、猴子；不要因轻功跑得快就越级追高血量怪。以幸运为主，敏捷满足飞镖武器和防具的要求；飞镖报价按一组查，不按一枚比较。

## 精准暗器后暴击路线：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 轻功 → 1（累计投入1点）
2. 精准暗器 → 5（累计投入6点）
3. 快速暗器 → 1（累计投入7点）
4. 精准暗器 → 20（累计投入22点）
5. 强力投掷 → 30（累计投入52点）
6. 轻功 → 20（累计投入71点）
7. 致命恢复 → 20（累计投入91点）
8. 快速暗器 → 20（累计投入110点）
9. 生命吸收 → 11（累计投入121点）

70 级目标：轻功 20；精准暗器 20；快速暗器 20；强力投掷 30；致命恢复 20；生命吸收 11。共投入121点。

## 依据与适用范围

多篇攻略交叉整理；方案为编辑建议，未统计全服使用率。
