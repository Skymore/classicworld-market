# 飞侠一转：飞镖开局与纯刀免洗点

## 先决定是否愿意转刀洗点

目标刺客，选 Lucky Seven 飞镖路线。目标侠客而且希望一直用短刀、免洗点，选 Double Stab 路线。Sindit 是先用飞镖练、二转选择 Bandit、之后再转短刀的玩法，不能误解为同时拥有 Assassin 的二转技能。

## 为什么飞镖开局常被推荐

远程和跳投减少追怪与碰撞，Lucky Seven 是一转易用的攻击。对应代价是爪、飞镖和后续转刀准备。纯刀路线少一次切换决策，较早熟悉近战；两套都能继续发展，不能把愿意购买洗点的速练思路强塞给免洗点玩家。

## 加点取舍

飞镖先 Nimble Body 3，才能点 Keen Eyes。先开射程，再补主攻，随后补足射程、命中和 Dark Sight 前置。纯刀先形成 Double Stab 输出，再补 Nimble Body；Disorder 3 之后才能点 Dark Sight。不要把两个主攻和全部辅助同时点满。

主 LUK，DEX 或 STR 按实际武器需求规划；普通飞镖路线不需要为“以后也许玩力量刀”随手加 STR。20—35 可比较章鱼、Stirge、蚂蚁洞；短刀优先地面目标，远程路线更容易利用平台分工。

## 飞镖路线：可执行顺序

数字表示该技能加到的总等级，不是再加多少点。按从零开始的顺序执行，已有加点请按剩余 SP 调整。

1. Lucky Seven → 1（累计 1 SP）
2. Nimble Body → 3（累计 4 SP）
3. Keen Eyes → 1（累计 5 SP）
4. Lucky Seven → 20（累计 24 SP）
5. Keen Eyes → 15（累计 38 SP）
6. Nimble Body → 15（累计 50 SP）
7. Disorder → 3（累计 53 SP）
8. Dark Sight → 8（累计 61 SP）

30 级目标：Lucky Seven 20；Nimble Body 15；Keen Eyes 15；Disorder 3；Dark Sight 8。合计已用 61 / 61 SP。

## 纯短刀免洗点路线：可执行顺序

数字表示该技能加到的总等级，不是再加多少点。按从零开始的顺序执行，已有加点请按剩余 SP 调整。

1. Double Stab → 20（累计 20 SP）
2. Nimble Body → 15（累计 35 SP）
3. Disorder → 3（累计 38 SP）
4. Dark Sight → 20（累计 58 SP）
5. Disorder → 6（累计 61 SP）

30 级目标：Double Stab 20；Nimble Body 15；Disorder 6；Dark Sight 20。合计已用 61 / 61 SP。
