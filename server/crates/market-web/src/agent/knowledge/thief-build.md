# 飞侠一转：飞镖开局与纯刀免洗点

## 先决定是否愿意转刀洗点

目标刺客，选双飞斩飞镖路线。目标侠客而且希望一直用短刀、免洗点，选二连击路线。先玩飞镖再转短刀是先用飞镖练、二转选择侠客、之后再转短刀的玩法，不能误解为同时拥有刺客的二转技能。

## 为什么飞镖开局常被推荐

远程和跳投减少追怪与碰撞，双飞斩是一转易用的攻击。对应代价是爪、飞镖和后续转刀准备。纯刀路线少一次切换决策，较早熟悉近战；两套都能继续发展，不能把愿意购买洗点的速练思路强塞给免洗点玩家。

## 加点取舍

飞镖先灵巧术 3，才能点远程暗器。先开射程，再补主攻，随后补足射程、命中和隐身术前置。纯刀先形成二连击输出，再补灵巧术；混乱术 3 之后才能点隐身术。不要把两个主攻和全部辅助同时点满。

主幸运，敏捷或力量按实际武器需求规划；普通飞镖路线不需要为“以后也许玩力量刀”随手加力量。20—35 可比较章鱼、蝙蝠、蚂蚁洞；短刀优先地面目标，远程路线更容易利用平台分工。

## 飞镖路线：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 双飞斩 → 1（累计投入1点）
2. 灵巧术 → 3（累计投入4点）
3. 远程暗器 → 1（累计投入5点）
4. 双飞斩 → 20（累计投入24点）
5. 远程暗器 → 15（累计投入38点）
6. 灵巧术 → 15（累计投入50点）
7. 混乱术 → 3（累计投入53点）
8. 隐身术 → 8（累计投入61点）

30 级目标：双飞斩 20；灵巧术 15；远程暗器 15；混乱术 3；隐身术 8。共投入61点。

## 纯短刀免洗点路线：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 二连击 → 20（累计投入20点）
2. 灵巧术 → 15（累计投入35点）
3. 混乱术 → 3（累计投入38点）
4. 隐身术 → 20（累计投入58点）
5. 混乱术 → 6（累计投入61点）

30 级目标：二连击 20；灵巧术 15；混乱术 6；隐身术 20。共投入61点。
