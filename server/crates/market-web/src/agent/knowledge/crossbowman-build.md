# 弩手 Crossbowman：穿透群攻与控制分支

## 默认路线

Iron Arrow 1 起手；Crossbow Mastery 5 → Crossbow Booster 5 → Soul Arrow: Crossbow 1，先解决基础与省箭，再满 Mastery，随后发展 Iron Arrow。和猎人一样，Mastery 是重要基础；但弩的群攻是穿透路线，不能照搬爆炸箭的站位。

## 为什么不只看六只总伤害

Iron Arrow 可以穿透多个目标，后续目标伤害会降低；要找目标实际排在射线上的平台。地图里总共有六只，并不代表一次都能打到。Final Attack: Crossbow 是单体高倍率补充，Bow 版本则有不同目标数，两者不能混写。

## 省箭与后期分歧

Classic World Guide 更早满 Mastery、稍后才开 Soul Arrow；NiaMeowDB 较早省箭。箭和补给充足时可采用前者，否则下方方案更省事。两种都必须先满足 Booster 5。

后期一种路线补满 Booster / Soul Arrow，减少补状态；另一种留较低持续，把点移去 Amazon's Judgement 控制。前者适合固定平台、求省心；后者适合需要拉开距离的人。不要因为有最大等级就把六个技能全喊满，121 SP 不够全部上限。

## 练级衔接

一转单体仍能过渡，群攻成形后优先平直平台的蘑菇、Evil Eye 等；有较硬单体时再发挥 Final Attack。主 DEX，STR 按当前弩的装备需求，不能套猎人弓的同一数值。

## 穿透群攻路线：可执行顺序

数字表示该技能加到的总等级，不是再加多少点。按从零开始的顺序执行，已有加点请按剩余 SP 调整。

1. Iron Arrow → 1（累计 1 SP）
2. Crossbow Mastery → 5（累计 6 SP）
3. Crossbow Booster → 5（累计 11 SP）
4. Soul Arrow: Crossbow → 1（累计 12 SP）
5. Final Attack: Crossbow → 1（累计 13 SP）
6. Crossbow Mastery → 20（累计 28 SP）
7. Iron Arrow → 30（累计 57 SP）
8. Amazon's Judgement → 1（累计 58 SP）
9. Crossbow Booster → 20（累计 73 SP）
10. Soul Arrow: Crossbow → 20（累计 92 SP）
11. Final Attack: Crossbow → 30（累计 121 SP）

70 级目标：Iron Arrow 30；Crossbow Mastery 20；Crossbow Booster 20；Soul Arrow: Crossbow 20；Final Attack: Crossbow 30；Amazon's Judgement 1。合计已用 121 / 121 SP。

## 依据与适用范围

多篇攻略交叉整理；方案为编辑建议，未统计全服使用率。
