# 弩手：铁箭群攻与控制分支

## 默认路线

铁箭 1 起手；精准弩 5 → 快速弩 5 → 无形箭：弩 1，先解决基础与省箭，再满精准弩，随后发展铁箭。和猎人一样，精准弩是重要基础；但弩的群攻是穿透路线，不能照搬炸弹箭的站位。

## 为什么不只看六只总伤害

铁箭可以穿透多个目标，后续目标伤害会降低；要找目标实际排在射线上的平台。地图里总共有六只，并不代表一次都能打到。终极攻击：弩是单体高倍率补充，弓版本则有不同目标数，两者不能混写。

## 省箭与后期分歧

经典世界攻略站更早满精准弩、稍后才开无形箭；喵喵资料站较早省箭。箭和补给充足时可采用前者，否则下方方案更省事。两种都必须先满足快速弩 5。

后期一种路线补满快速弩或无形箭，减少补状态；另一种留较低持续，把点移去亚马逊的审判控制。前者适合固定平台、求省心；后者适合需要拉开距离的人。不要因为有最大等级就把六个技能全喊满，121 技能点不够把所有技能都加满。

## 练级衔接

一转单体仍能过渡，群攻成形后优先平直平台的蘑菇、火独眼兽等；有较硬单体时再发挥终极攻击。主敏捷，力量按当前弩的装备需求，不能套猎人的弓的同一数值。

## 穿透群攻路线：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 铁箭 → 1（累计投入1点）
2. 精准弩 → 5（累计投入6点）
3. 快速弩 → 5（累计投入11点）
4. 无形箭：弩 → 1（累计投入12点）
5. 终极攻击：弩 → 1（累计投入13点）
6. 精准弩 → 20（累计投入28点）
7. 铁箭 → 30（累计投入57点）
8. 亚马逊的审判 → 1（累计投入58点）
9. 快速弩 → 20（累计投入73点）
10. 无形箭：弩 → 20（累计投入92点）
11. 终极攻击：弩 → 30（累计投入121点）

70 级目标：铁箭 30；精准弩 20；快速弩 20；无形箭：弩 20；终极攻击：弩 30；亚马逊的审判 1。共投入121点。

多篇攻略交叉整理；方案为编辑建议，未统计全服使用率。
