# 剑客：精准技能、愤怒之火与武器路线

## 默认路线

普通装备可以先单修剑：学一级冲锋，把精准剑加到 5 级，解锁快速剑，再开愤怒之火。之后补满精准剑，逐步提高愤怒之火和终极剑击。想用斧也可以走相同顺序，但要把精准、快速和终极攻击全部换成斧系技能，避免两边各投一半技能点。

## 为什么这样选

精准技能改善低伤害波动；精准剑还提供命中，适合装备一般、目标容易打空的人。斧的流血更依赖敌人活得够久，清一两击的小怪未必兑现全部收益。愤怒之火能服务身边的物理队友，但也降低物防，要把药耗算进去。

## 备选方案

固定物理队可把愤怒之火的后续投入提前；自己已经稳定收怪、主要时间花在追怪时，可先提高冲锋。喵喵资料站偏先伤害，经典世界攻略站更愿意提前机动，分歧来自地图与队伍。快速剑早期一阶已有攻速提升，追加点主要改善持续与消耗。

双手武器是简单输出起点；单手加盾更看重防御，需要把多打一击的时间与少受伤的收益一起比较。武器市场价格每次都应现查，不能从旧攻略推断哪种始终便宜。

## 操作与练级

终极攻击在本服是触发后获得可使用窗口，要主动使用；不是旧版强制自动追击。仍以强力攻击或群体攻击清怪，冲锋用于有价值的聚怪和移动。蚂蚁洞、野猪和挖掘场是中期对照；不要为了追地图等级而放弃稳定击杀。

## 单修剑、先稳定输出：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 冲锋 → 1（累计投入1点）
2. 精准剑 → 5（累计投入6点）
3. 快速剑 → 1（累计投入7点）
4. 愤怒之火 → 1（累计投入8点）
5. 终极剑击 → 1（累计投入9点）
6. 精准剑 → 20（累计投入24点）
7. 愤怒之火 → 30（累计投入53点）
8. 终极剑击 → 30（累计投入82点）
9. 快速剑 → 20（累计投入101点）
10. 冲锋 → 20（累计投入120点）

70 级目标：冲锋 20；精准剑 20；快速剑 20；愤怒之火 30；终极剑击 30。共投入120点，可用121点，保留 1 技能点，不为凑满强点另一武器系。

## 依据与适用范围

多篇攻略交叉整理；方案为编辑建议，未统计全服使用率。
