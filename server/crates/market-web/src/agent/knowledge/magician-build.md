# 法师一转：魔灵弹、魔法爪与药费

## 两种常见路线

魔法爪路线适合不想受地形阻挡影响、愿意承担较高每次耗蓝的人；魔灵弹路线适合能找到平直射击位置、需要控制药费的人。两边都有攻略和玩家支持，不能把其中一种说成全服统一答案。魔法爪先要魔灵弹 1。

## 默认推荐与理由

新手地形不熟时可选下方魔法爪通用方案；资金紧张且常驻平地，则选魔灵弹省药方案。主攻先达到稳定击杀所需等级，再补回复和魔法铠甲。只堆回复、长期靠一级攻击多打几次，也可能更费蓝；反过来，升级主攻却没减少击杀次数时，不必急着追满。

魔法盾把部分伤害转到魔法值，不等于减少总消耗。下方方案偏日常安全地图的经济性；遇到高伤害区域或首领，要重新评估魔法盾与血蓝安全余量。不要把“平时可少开魔法盾”扩写为“任何时候都关”。最大魔力提升是百分比加成，晚加不永久损失早期升级魔法值。

## 练级衔接与属性

主智力，幸运补到实际法杖/防具需求；先扣装备上的幸运。一转可从绿水灵、绿蘑菇过渡到刺蘑菇和僵尸蘑菇。弹道经常被地形挡住时，换站位或用魔法爪；20—35 不必越级追高血量怪。

两套点数方案互斥，不要把两个主攻都满、再照搬同样的防御终点。二转仍可用一转满级攻击过渡，新学的低级技能未必立刻更强。

## 魔法爪通用路线：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 魔灵弹 → 1（累计投入1点）
2. 魔力恢复 → 1（累计投入2点）
3. 魔法爪 → 20（累计投入22点）
4. 魔法盾 → 3（累计投入25点）
5. 魔力恢复 → 3（累计投入27点）
6. 最大魔力提升 → 1（累计投入28点）
7. 魔法铠甲 → 20（累计投入48点）
8. 魔力恢复 → 15（累计投入60点）
9. 最大魔力提升 → 2（累计投入61点）

30 级目标：魔灵弹 1；魔力恢复 15；魔法爪 20；魔法盾 3；最大魔力提升 2；魔法铠甲 20。共投入61点。

1. 魔灵弹 → 1（累计投入1点）
2. 魔力恢复 → 1（累计投入2点）
3. 魔灵弹 → 20（累计投入21点）
4. 魔力恢复 → 15（累计投入35点）
5. 最大魔力提升 → 1（累计投入36点）
