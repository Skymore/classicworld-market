# 准骑士：剑与钝器、威胁的投入

## 默认路线

普通装备可以先走剑系：学一级冲锋，把精准剑加到 5 级，解锁快速剑，然后补满精准剑。威胁先学一级，再发展终极剑击。已有好钝器的玩家可以按同样思路加钝器技能，但不能拿剑的快速剑给钝器用。

## 为什么这样选

剑系的命中与较稳定伤害适合日常收怪；钝器的暴击收益更适合命中解决之后比较。威胁降低敌方移速和物防，不是旧版记忆里的同名效果。对原本一两击就死的小怪，施放减益未必省时间；面对较硬目标才更值得试。

## 备选与分歧

喵喵资料站的例子较早发展终极攻击，再补威胁；另一路更早补冲锋来改善移动与药费。若你几乎只群刷，单体终极攻击的优先级可以后移；如果常打单体或首领，则更有理由提前。双修武器换来灵活性，也会推迟核心技能，不作为普通新手默认。

## 练级与版本

近战优先地面密集平台，把单攻与群攻按实际目标数切换。35—50 先比较蚂蚁洞、野猪、风独眼兽，再考虑更硬的怪。当前二转有冲锋；不要从旧版准骑士表中补入本服二转没有的伤害防护技能或尚未开放的三转属性攻击。

## 单修剑、先稳定输出：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 冲锋 → 1（累计投入1点）
2. 精准剑 → 5（累计投入6点）
3. 快速剑 → 1（累计投入7点）
4. 威胁 → 1（累计投入8点）
5. 精准剑 → 20（累计投入23点）
6. 终极剑击 → 30（累计投入53点）
7. 威胁 → 30（累计投入82点）
8. 快速剑 → 20（累计投入101点）
9. 冲锋 → 20（累计投入120点）

70 级目标：冲锋 20；精准剑 20；快速剑 20；威胁 30；终极剑击 30。共投入120点，可用121点，保留 1 技能点，不为凑满强点另一武器系。

## 依据与适用范围

多篇攻略交叉整理；方案为编辑建议，未统计全服使用率。
