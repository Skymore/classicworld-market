# 火毒：火焰箭单体、毒群攻与机动省药

## 默认：先火箭，补增益和机动

开快速移动、魔力吸收后发展火焰箭，接魔力吸收 3 → 精神力，再改善快速移动和群攻。适合预算有限、单体目标多的玩家。新版火焰箭有灼烧，毒雾术则会在命中后爆开、打到附近多个目标，不能按旧版“二转毒只碰一只”理解。

## 第二条：毒群攻提前

如果常驻的实际平台能持续聚到多只，且蓝药负担得起，可以先发展毒雾术，再回头补火焰箭。喵喵资料站的常规表把毒群攻放得较早，另一个指南更强调快速移动的经济性；本篇默认采用较稳的单体与移动顺序。

## 为什么不能直接抄等级阈值

部分社区法师页面明确提示伤害公式变化，原来“某级必定两发”的结论已不准。选择看你当前武器、智力、目标抗性和施法次数。打火抗怪时改用中性一转攻击作比较，不要只因二转技能名字更高级就一直用火箭。

## 练级衔接

30—40 以蘑菇、野猪或挖掘场低血量怪作对照；之后才比较小幽灵、龙虾、僵尸猴、风独眼兽。候选地图要再查实际抗性和击杀次数。遗忘山谷延期后，依赖其中怪物的旧火毒路线不能直接照用。

缓速术需要快速移动 5；精神力需要魔力吸收 3。下方完整路线已按前置排列。火、毒和一转中性攻击可以按目标切换，而不是强求一个技能包办。

## 火箭单体、机动省药：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 快速移动 → 1（累计投入1点）
2. 魔力吸收 → 1（累计投入2点）
3. 火焰箭 → 30（累计投入32点）
4. 魔力吸收 → 3（累计投入34点）
5. 精神力 → 20（累计投入54点）
6. 快速移动 → 20（累计投入73点）
7. 毒雾术 → 30（累计投入103点）
8. 魔力吸收 → 20（累计投入120点）
9. 缓速术 → 1（累计投入121点）

70 级目标：快速移动 20；魔力吸收 20；火焰箭 30；精神力 20；毒雾术 30；缓速术 1。共投入121点。
