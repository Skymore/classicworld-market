# 火毒：火箭单体、毒群攻与机动省药

## 默认：先火箭，补增益和机动

开 Teleport、MP Eater 后发展 Fire Arrow，接 MP Eater 3 → Meditation，再改善 Teleport 和群攻。适合普通资金、单体目标多的玩家。新版 Fire Arrow 有灼烧，Poison Breath 则会在命中后爆开、打到附近多个目标，不能按旧版“二转毒只碰一只”理解。

## 第二条：毒群攻提前

如果常驻的实际平台能持续聚到多只，且蓝药负担得起，可以先发展 Poison Breath，再回头补 Fire Arrow。NiaMeowDB 的常规表把毒群攻放得较早，另一个指南更强调 Teleport 的经济性；本篇默认采用较稳的单体与移动顺序。

## 为什么不能直接抄等级阈值

部分社区法师页面明确提示伤害公式变化，原来“某级必定两发”的结论已不准。选择看你当前武器、INT、目标抗性和施法次数。打火抗怪时改用中性一转攻击作比较，不要只因二转技能名字更高级就一直用火箭。

## 练级衔接

30—40 以蘑菇、野猪或挖掘场低血量怪作对照；之后才比较 Jr. Wraith、Lorang、Zombie Lupin、Curse Eye。候选地图要再查实际抗性和击杀次数。Forgotten Hollow 延期后，依赖其中怪物的旧火毒路线不能直接照用。

Slow 需要 Teleport 5；Meditation 需要 MP Eater 3。下方完整路线已按前置排列。火、毒和一转中性攻击可以按目标切换，而不是强求一个技能包办。

## 火箭单体、机动省药：可执行顺序

数字表示该技能加到的总等级，不是再加多少点。按从零开始的顺序执行，已有加点请按剩余 SP 调整。

1. Teleport → 1（累计 1 SP）
2. MP Eater → 1（累计 2 SP）
3. Fire Arrow → 30（累计 32 SP）
4. MP Eater → 3（累计 34 SP）
5. Meditation → 20（累计 54 SP）
6. Teleport → 20（累计 73 SP）
7. Poison Breath → 30（累计 103 SP）
8. MP Eater → 20（累计 120 SP）
9. Slow → 1（累计 121 SP）

70 级目标：Teleport 20；MP Eater 20；Fire Arrow 30；Meditation 20；Poison Breath 30；Slow 1。合计已用 121 / 121 SP。
