# 全职业加点总览：默认路线与主要分歧

## 怎么选默认方案

本辑面向经典世界国际服，覆盖四个一转和十个二转。默认以普通装备、可持续练级、尽量免洗点为目标。这里的“常见路线”指多篇攻略或玩家讨论反复出现的选择，没有全服加点使用率统计；不同攻略引用同一作者或同一客户端，不算独立实测。

- 战士：先解决命中和击杀次数，再区分剑客 Fighter 的 Rage、准骑士 Page 的 Threaten、枪战士 Spearman 的矛系机动性。
- 法师：一转选 Energy Bolt 省药或 Magic Claw 地形适应；火毒、冰雷各有单体与群攻路线；牧师比较圣箭单练、机动与队伍辅助。
- 弓箭手：一转 Arrow Blow 是易执行的起点；猎人和弩手二转都先解决 Mastery，再形成群攻能力。最后一批点有续航、控制和额外攻击的取舍。
- 飞侠：飞镖开局练级方便；确定玩刀且不想洗点可从 Double Stab 开始。刺客先 Mastery 后分暴击与 Haste；侠客区分纯刀与 Sindit 转刀。

## 十个二转怎么取舍

- 剑客 Fighter：默认先武器 Mastery，再 Rage 与 Final Attack，适合稳定近战练级；已有好斧可走斧系，比较流血收益与命中，避免早期分散双修。
- 准骑士 Page：默认单修剑、Mastery 后发展 Final Attack 与 Threaten；好钝器也可走对应路线，比较暴击收益。不能按旧版当成没有特色的过渡职业。
- 枪战士 Spearman：普通练级偏矛系移动与 Rush；有强枪或高防御目标可走枪系。追怪耗时多先机动，固定打硬怪则可提前 Final Attack。
- 火毒 F/P Wizard：默认 Fire Arrow 单体成形、补 Meditation 与机动；稳定密集平台才考虑 Poison Breath 提前，省药与清群能力二选优先。
- 冰雷 I/L Wizard：默认 Cold Beam 单体省药，再补群攻；能常态命中多只且药费够时，Thunder Bolt 可先。是否群攻不由职业名字决定。
- 牧师 Cleric：默认圣箭单练，再补自身减伤；固定队更重 Heal / Bless，跑图占比大也有人优先 Teleport。当前 Heal 群攻路线需实测目标数量和蓝耗。
- 猎人 Hunter：默认 Mastery 打基础、Arrow Bomb 清群；单体更常见可提前 Final Attack。后段省箭/攻速状态持续和控制需要取舍。
- 弩手 Crossbowman：同样先 Mastery，再 Iron Arrow；选择能形成穿透射线的平台。后期分省心长状态与 Amazon's Judgement 控制，不能照搬猎人的群攻站位。
- 刺客 Assassin：默认 Mastery 后暴击，适合击杀伤害不足；地图大、跑图慢或队伍需要机动时 Haste 更早。飞镖回收和药耗也算收益。
- 侠客 Bandit：免洗点纯刀先 Mastery 再 Savage Blow；已有爪/飞镖开局的 Sindit 单列切换成本。后段 Steal 攻击增益与 Haste/回复优先各有适用场景。

## 共同的判断方法

先问“这批点能否少打一击、少一次补给或少跑一段路”，再看面板。主攻技能升一级却仍要打相同次数时，可以先补命中、回复或位移；伤害不够稳定收怪时，继续补主攻或 Mastery。留点卡耗蓝档位是针对已知装备和地图的优化，不是让所有新手照着一直不点技能。

属性 AP 的通用方向是：战士 STR、法师 INT、弓手 DEX、飞侠 LUK；副属性按实际装备需求扣除装备提供的数值。不要把示例角色的裸属性当成每个人的硬标准。DEX 战士、STR 弓手、STR 刀飞属于需要单独配装或洗点计划的分支。

## 阅读顺序

先读一转，再读目标二转，最后看“升级路线：1—100级”。每篇职业文档给出默认顺序、备选条件、理由和可核算的总点数。30 级的一转例子是 61 SP，70 级的二转例子是 121 SP；不同转职的点数分开，不能拿二转点补一转。70 级只是对照节点，不代表当前已经开放三转。

## 版本纠错

Grand Launch 官方公告把上限定为 100 级，并明确 Forgotten Hollow 延后到 11 月；旧攻略出现该区域，不表示现在能去。三转、天空之城和雪域的测试服内容不能并入当前路线。公开的热门全职业图文贴也修正过弓手顺序；本辑采用后续文字说明和客户端前置，不照搬原图。
