# 全职业加点总览：默认路线与主要分歧

## 怎么选默认方案

这份指南面向经典世界国际服，覆盖四个一转和十个二转。默认以普通装备、可持续练级、尽量免洗点为目标。这里的“常见路线”指多篇攻略或玩家讨论反复出现的选择，没有全服加点使用率统计；不同攻略引用同一作者或同一客户端，不算独立实测。

- 战士：先解决命中和击杀次数，再区分剑客的愤怒之火、准骑士的威胁、枪战士的矛系机动性。
- 法师：一转选魔灵弹省药或魔法爪地形适应；火毒、冰雷各有单体与群攻路线；牧师比较圣箭单练、机动与队伍辅助。
- 弓箭手：一转断魂箭是易执行的起点；猎人和弩手二转都先解决精准技能，再形成群攻能力。最后一批点有续航、控制和额外攻击的取舍。
- 飞侠：飞镖开局练级方便；确定玩刀且不想洗点可从二连击开始。刺客先精准技能后分暴击与轻功；侠客区分纯刀与先飞镖后转刀。

## 十个二转怎么取舍

- 剑客：默认先武器精准技能，再愤怒之火与终极攻击，适合稳定近战练级；已有好斧可走斧系，比较流血收益与命中，避免早期分散双修。
- 准骑士：默认单修剑、精准技能后发展终极攻击与威胁；好钝器也可走对应路线，比较暴击收益。不能按旧版当成没有特色的过渡职业。
- 枪战士：普通练级偏矛系移动与冲锋；有强枪或高防御目标可走枪系。追怪耗时多先机动，固定打硬怪则可提前终极攻击。
- 火毒法师：默认火箭术单体成形、补精神力与机动；稳定密集平台才考虑毒息术提前，省药与清群能力二选优先。
- 冰雷法师：默认冰箭单体省药，再补群攻；能常态命中多只且药费够时，雷电术可先。是否群攻不由职业名字决定。
- 牧师：默认圣箭单练，再补自身减伤；固定队更重治愈术或祝福，跑图占比大也有人优先瞬间移动。当前治愈术群攻路线需实测目标数量和蓝耗。
- 猎人：默认精准技能打基础、爆炸箭清群；单体更常见可提前终极攻击。后段省箭/攻速状态持续和控制需要取舍。
- 弩手：同样先精准技能，再穿透箭；选择能形成穿透射线的平台。后期分省心长状态与亚马逊审判控制，不能照搬猎人的群攻站位。
- 刺客：默认精准技能后暴击，适合击杀伤害不足；地图大、跑图慢或队伍需要机动时轻功更早。飞镖回收和药耗也算收益。
- 侠客：免洗点纯刀先精准技能再六连斩；已有爪/飞镖开局的先玩飞镖再转短刀单列切换成本。后段偷窃术攻击增益与轻功/回复优先各有适用场景。

## 共同的判断方法

先问“这批点能否少打一击、少一次补给或少跑一段路”，再看面板。主攻技能升一级却仍要打相同次数时，可以先补命中、回复或位移；伤害不够稳定收怪时，继续补主攻或精准技能。留点卡耗蓝档位是针对已知装备和地图的优化，不是让所有新手照着一直不点技能。

属性点的通用方向是：战士主加力量、法师主加智力、弓手主加敏捷、飞侠主加幸运；副属性按实际装备需求扣除装备提供的数值。不要把示例角色的裸属性当成每个人的硬标准。敏捷战士、力量弓手、力量刀飞属于需要单独配装或洗点计划的分支。

## 阅读顺序

先读一转，再读目标二转，最后看“升级路线：1—100级”。每篇职业文档给出默认顺序、备选条件、理由和可核算的总点数。30 级的一转例子是 61 技能点，70 级的二转例子是 121 技能点；不同转职的点数分开，不能拿二转点补一转。70 级只是对照节点，不代表当前已经开放三转。

## 版本纠错

开服公告把上限定为 100 级，并明确遗忘山谷延后到 11 月；旧攻略出现该区域，不表示现在能去。三转、天空之城和雪域的测试服内容不能并入当前路线。公开的热门全职业图文贴也修正过弓手顺序；这份指南采用后续文字说明和客户端前置，不照搬原图。

## 依据与适用范围

多篇攻略交叉整理；方案为编辑建议，未统计全服使用率。
