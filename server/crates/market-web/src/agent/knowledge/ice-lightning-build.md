# 冰雷：单体省药与雷电群攻两条路线

## 默认：冰箭单体省药

先开瞬间移动和魔力吸收，主升冰箭；之后魔力吸收至 3 才能开精神力。预算有限、怪物分布较散时，先补精神力，再发展雷电术。冰箭是单体冰属性攻击并减速，不要按老版完全冰冻来设计安全站位。

## 另一条：雷电术群攻

已有稳定密集平台、能连续命中多只且负担药费时，可以把雷电术提到冰箭前。它最多攻击六只，但每次实际只命中一只时并没有六倍收益。一份职业攻略推荐先单体，讨论中也多次提醒群攻蓝耗；另一份职业攻略则强调把攻击点数和目标地图配套，作者还明确撤回旧伤害阈值的准确性。

## 如何判断该换路线

先连续试打同一平台，记录每次群攻平均打中几只、每只几次死、蓝药支出。聚怪总要跑很远或经常被人打散，就回单体路线。不要把“模拟器两只起可能领先”写成任何角色的固定换点标准。

## 练级衔接

30—40 可以继续用一转攻击刷蘑菇，二转技能等级足够再换。单体可比较 [烧毁之地一区](/map/10004111)的火野猪：正式野外版本是 32 级、842 生命值，和野猪不同；野猪的领土没有这种怪，里面 1395 生命值的怪是小布吉。群攻可比较 [蚂蚁洞一层](/map/10005060)的刺蘑菇或僵尸蘑菇。还要看实际击杀次数和药耗；缺少输出就不要跳去高血量地图。

## 后续取舍

瞬间移动提高等级会降低耗蓝；转场频繁时可在主攻成形后提前。魔力吸收有 5 秒间隔且受怪物魔法值限制，不能当永久无限蓝。下方完整表是单体起手，群攻版交换两个主攻的优先级即可，仍需完整保留精神力与缓速术的前置。

## 单体省药、后补群攻：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 瞬间移动 → 1（累计投入1点）
2. 魔力吸收 → 1（累计投入2点）
3. 冰箭 → 30（累计投入32点）
4. 魔力吸收 → 3（累计投入34点）
5. 精神力 → 20（累计投入54点）
6. 雷电术 → 30（累计投入84点）
7. 魔力吸收 → 20（累计投入101点）
8. 瞬间移动 → 20（累计投入120点）
9. 缓速术 → 1（累计投入121点）

70 级目标：瞬间移动 20；魔力吸收 20；冰箭 30；精神力 20；雷电术 30；缓速术 1。共投入121点。
