# 冰雷：单体省药与雷电群攻两条路线

## 默认：Cold Beam 单体省药

先开 Teleport 和 MP Eater，主升 Cold Beam；之后 MP Eater 至 3 才能开 Meditation。普通资金、怪比较分散时，先补 Meditation，再发展 Thunder Bolt。Cold Beam 是单体冰属性攻击并减速，不要按老版完全冰冻来设计安全站位。

## 另一条：Thunder Bolt 群攻

已有稳定密集平台、能连续命中多只且负担药费时，可以把 Thunder Bolt 提到 Cold Beam 前。它最多攻击六只，但每次实际只命中一只时并没有六倍收益。NiaMeowDB 推荐先单体，讨论中也多次提醒群攻蓝耗；Classic World Guide 则强调把攻击点数和目标地图配套，作者还明确撤回旧伤害阈值的准确性。

## 如何判断该换路线

先连续试打同一平台，记录每次群攻平均打中几只、每只几次死、蓝药支出。聚怪总要跑很远或经常被人打散，就回单体路线。不要把“模拟器两只起可能领先”写成任何角色的固定换点标准。

## 练级衔接

30—40 可以继续用一转攻击刷蘑菇，二转技能等级足够再换。Fire Boar 可作为 Cold Beam 的属性目标候选，但还要看命中与实际击杀次数；群攻先试蚂蚁洞的密集平台。缺少输出就不要因为“冰雷”两个字跳去高血量地图。

## 后续取舍

Teleport 提高等级会降低耗蓝；转场频繁时可在主攻成形后提前。MP Eater 有 5 秒间隔且受怪物 MP 限制，不能当永久无限蓝。下方完整表是单体起手，群攻版交换两个主攻的优先级即可，仍需完整保留 Meditation 与 Slow 的前置。

## 单体省药、后补群攻：可执行顺序

数字表示该技能加到的总等级，不是再加多少点。按从零开始的顺序执行，已有加点请按剩余 SP 调整。

1. Teleport → 1（累计 1 SP）
2. MP Eater → 1（累计 2 SP）
3. Cold Beam → 30（累计 32 SP）
4. MP Eater → 3（累计 34 SP）
5. Meditation → 20（累计 54 SP）
6. Thunder Bolt → 30（累计 84 SP）
7. MP Eater → 20（累计 101 SP）
8. Teleport → 20（累计 120 SP）
9. Slow → 1（累计 121 SP）

70 级目标：Teleport 20；MP Eater 20；Cold Beam 30；Meditation 20；Thunder Bolt 30；Slow 1。合计已用 121 / 121 SP。
