# 装备与买卖：问法、属性和报价依据

选装备时将部位、职业和等级拆成筛选条件。比如“25弓去哪买”问的是哪里能买到 25 级的弓，不是 25 级弓手去哪练级。通用装备也可能适合该职业；目录职业限制空白只能说尚未记录，不能直接断定不可穿或完全通用。属性必须查实际数据，不能凭“披风”推断都加敏捷或攻击。

想买：查物品、玩家摊位和商店，比较单价、数量、属性、位置与观察时间。想卖：查站内价格建议、当前挂牌和成交价，区分快卖与正常卖。报价只覆盖本站采集来源，不是全市场实时保证。

助手不知道玩家背包，也不能替玩家上架。掉落表有旧第二轮测试参考时会标注。此文只讲方法，实际询价时应让助手重新查报价，不要沿用旧对话里的数字。
