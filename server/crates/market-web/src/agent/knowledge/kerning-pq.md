# 废弃都市组队任务 KPQ 的入场信息

Grand Launch 官方说明中，First Time Together 是 Kerning City 的组队任务，角色需 21 级及以上，在 Kerning City 找 Lakelis。该次发布说明指定可用频道为 CH3–CH12；更早攻略里的 CH3–CH5 或 CH3–CH7 是旧安排。

社区按正式版任务记录整理的入场人数为 4 人。任务包含合作解谜、清怪并挑战 King Slime。精确解谜、奖励和当前频道若无可靠资料，不要把其他服攻略里的组合直接说成标准答案。

问“今天在哪些频道”“最新玩法改了吗”必须联网核对。不要把测试服或现代服的其他组队副本当成本服现在可玩。
