# 弓手一转：主攻、暴击、射程与击退

## 默认选择

普通练级先把强力箭作为主攻，及早拿一阶射程和击退，再补致命射击。两份职业攻略都给出强力箭路线；差别主要在何时补暴击、保留低耗蓝档，以及最后的命中和击退分配。

## 为什么不机械先满暴击

暴击提高平均收益，却不能保证每次都出现。普通攻击伤害刚好不够收怪时，主攻提高到稳定少打一箭通常更直接。亚马逊之眼改善射程，强力击退则处理贴身挥弓；只堆伤害而忽略射击空间，实际效率未必提高。

## 两个终点与另一主攻

默认集中术 10、强力击退 1，适合仍会打空的地图。若命中已足，常见替代是集中术 3、强力击退 8，其余不变，仍是 61 技能点；8 级击退可处理更多贴身目标。不要把二转亚马逊审判和一转亚马逊之眼当同一个技能。

二连射也有人使用，适合喜欢分摊攻击到多个目标的玩法，但会多耗箭和蓝，不能只比较技能总倍率。若选它，先满足强力箭 1，并从其他项目重新分配点数；本篇默认完整表是强力箭版本，不可额外叠满二连射。

## 练级与二转选择

主敏捷、力量满足装备。20—35 远程可比较蝙蝠地图和蘑菇地图，贴身区多时换平台；二转猎人用弓、弩手用弩。两者的精准技能都是重要转折，不要仅凭一转伤害波动判断二转强弱。

## 强力箭与命中路线：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 强力箭 → 1（累计投入1点）
2. 亚马逊之眼 → 1（累计投入2点）
3. 强力击退 → 1（累计投入3点）
4. 强力箭 → 20（累计投入22点）
5. 致命射击 → 15（累计投入37点）
6. 亚马逊之眼 → 15（累计投入51点）
7. 集中术 → 10（累计投入61点）

30 级目标：强力箭 20；亚马逊之眼 15；强力击退 1；致命射击 15；集中术 10。共投入61点。

## 依据与适用范围

多篇攻略交叉整理；方案为编辑建议，未统计全服使用率。
