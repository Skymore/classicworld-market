# 枪战士 Spearman：矛练级与枪的取舍

## 默认路线

本辑以 Polearm 矛系练级为默认：Mastery 先形成基础，Booster 开一阶，随后适当补持续和 Rush。NiaMeowDB 也把矛视为较易上手的练级选择，虽然它展示的完整示例是枪；Classic World Guide 更明确优先矛。下方是结合两者的机动优先方案。

## 为什么用矛

Polearm Mastery 提供移动速度，对追怪时间多的战士很实用。Spear Mastery 则有概率无视物防，收益更依赖敌人防御与武器条件。你已经有一把明显更好的枪时，可以单修枪；更换整套 Mastery、Booster、Final Attack，不需要把矛路线神化为任何装备下都赢。

## 先机动还是先追加攻击

追怪、聚怪和频繁补给是瓶颈时，先补 Rush/Booster；高血量单体多、愿意主动使用触发技能时，可以在 Mastery 后先满 Final Attack。Iron Will 提供防御和防击退机会，站位老被打断时价值更高。本站顺序偏日常机动，另一顺序也成立。

## 不要照搬的旧经验

当前二转没有 Hyper Body；也不能为尚未开放的三转先断言必须双修枪矛。Final Attack 是触发后主动释放，并带吸血条件，不是每次自动回血。选地面密集区，拿低等级快清图与高等级少怪图实测比较。

## 矛系机动练级路线：可执行顺序

数字表示该技能加到的总等级，不是再加多少点。按从零开始的顺序执行，已有加点请按剩余 SP 调整。

1. Rush → 1（累计 1 SP）
2. Polearm Mastery → 5（累计 6 SP）
3. Polearm Booster → 1（累计 7 SP）
4. Final Attack: Polearm → 1（累计 8 SP）
5. Polearm Mastery → 20（累计 23 SP）
6. Polearm Booster → 10（累计 32 SP）
7. Rush → 20（累计 51 SP）
8. Final Attack: Polearm → 30（累计 80 SP）
9. Iron Will → 30（累计 110 SP）
10. Polearm Booster → 20（累计 120 SP）

70 级目标：Rush 20；Polearm Mastery 20；Polearm Booster 20；Final Attack: Polearm 30；Iron Will 30。合计已用 120 / 121 SP，保留 1 SP，不为凑满强点另一武器系。
