# 枪战士：矛练级与枪的取舍

## 默认路线

这份指南默认用矛练级：先把精准矛点到能学快速矛的等级，再补突进和状态持续时间。一份攻略把矛视为较易上手的选择，另一份更明确推荐矛；不过枪也有适合的装备和目标。下面的点法侧重移动和日常练级。

## 为什么用矛

精准矛提供移动速度，适合经常追怪的玩家。精准枪则有概率无视物理防御，面对高防御目标可能更有价值。如果已经有一把明显更好的枪，可以单修枪，但要把精准、快速和终极攻击一起换成枪系技能。

## 先机动还是先追加攻击

追怪、聚怪和频繁补给是瓶颈时，先补突进/快速矛；高血量单体多、愿意主动使用触发技能时，可以在精准技能后先满终极攻击。极限防御提供防御和防击退机会，站位总被打断时价值更高。本站顺序偏日常机动，另一顺序也成立。

## 不要照搬的旧经验

当前二转没有神圣之火；也不能为尚未开放的三转先断言必须双修枪矛。终极攻击是触发后主动释放，并带吸血条件，不是每次自动回血。选地面密集区，拿低等级快清图与高等级少怪图实测比较。

## 矛系机动练级路线：可执行顺序

数字表示该技能最终达到的等级，不是再加多少点。以下顺序适合尚未加点的角色；已经分配过技能点的角色，要按剩余点数调整。

1. 突进 → 1（累计投入1点）
2. 精准矛 → 5（累计投入6点）
3. 快速矛 → 1（累计投入7点）
4. 终极攻击：矛 → 1（累计投入8点）
5. 精准矛 → 20（累计投入23点）
6. 快速矛 → 10（累计投入32点）
7. 突进 → 20（累计投入51点）
8. 终极攻击：矛 → 30（累计投入80点）
9. 极限防御 → 30（累计投入110点）
10. 快速矛 → 20（累计投入120点）

70 级目标：突进 20；精准矛 20；快速矛 20；终极攻击：矛 30；极限防御 30。共投入120点，可用121点，保留 1 技能点，不为凑满强点另一武器系。
